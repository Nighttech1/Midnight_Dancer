# UI reference sources — Midnight Dancer

Пользователь кидает ссылку → команда вставляет блок (Android Compose first). Skill: `.cursor/skills/ui-block-from-link/SKILL.md`.

|-----|--------|
| https://mobbin.com/ | Реальные экраны apps (списки, табы, settings) |
| https://dribbble.com/ | Один компонент / dark neon |
| https://www.behance.net/ | Целые экраны |
| https://rive.app/community/ | Танцор / EQ / rhythm → `.riv` |

| https://developer.apple.com/design/human-interface-guidelines/ | iOS после Android |

## Бренд при вставке

OLED `#000000`, neon из `ColorTokens`, без дешёвых серых card-стопок, Decompose SoT.
