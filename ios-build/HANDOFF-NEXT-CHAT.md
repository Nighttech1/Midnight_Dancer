# Текст для нового чата (сборка / iOS)

Можно вставить целиком.

---

Mobile Next (облачный iPhone) — только когда уже есть готовый IPA и готовый сценарий «что тапать / какие скрины». Один короткий прогон в конце UI-волны, потом сразу release.

Нельзя:

- выделять телефон «на всякий случай» или пока идёт сборка;
- гонять Mobile Next на каждый мелкий тикет / отдельную кнопочку.

Правильный порядок: собрали экраны → собрали IPA → upload → allocate → короткий прогон + скрины → сразу отпустить телефон.

Проверка отдельных кусков логики/кода до этого — без облачного iPhone (тесты, при необходимости локальный Android).

**Дом всех материалов по сборке iOS:** папка `ios-build/` (карта в `ios-build/README.md`).  
KMP: `ios-build/kmp/` · готовые IPA: `ios-build/artifacts/current/` · облако: `ios-build/cloud-qa/` · старый Flutter: `ios-build/flutter-legacy/`.
