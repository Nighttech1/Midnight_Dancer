# Mobile Next — правила (экономия минут)

Hobby ≈ **20 минут в сутки**. Минуты тикают, пока телефон **выделен**, даже если агент ждёт сборку.

## Можно

Короткий прогон **в конце UI-волны**, когда уже есть:

1. готовый IPA в `ios-build/artifacts/current/`  
2. готовый сценарий «что тапать / какие скрины»

Порядок: **экраны → IPA → upload → allocate → короткий прогон + скрины → сразу release**.

## Нельзя

- выделять телефон «на всякий случай» или пока идёт сборка;  
- гонять Mobile Next на каждый мелкий тикет / отдельную кнопочку;  
- держать allocate во время Gradle / Codemagic / ожидания CI.

## До облачного iPhone

Проверка логики/кода — тесты и при необходимости локальный Android. Без Mobile Next.
