# Как Клиент сам смотрит телефоны (без вашего участия)

## Android

Клиент **сам** запускает:

```powershell
.\scripts\ensure-client-devices.ps1
```

Потом тыкает через `mobile-mcp` и в конце **присылает вам скрины** в чат.

Вам ничего жать не нужно (окно эмулятора может само появиться на столе).

## iPhone

Локально на Windows нельзя. Подключено облако **Mobile Next Cloud** (лучшее для агента):

- MCP: `mobilenext-cloud` → `https://app.mobilenext.ai/mcp`
- Клиент сам берёт iPhone, ставит IPA, смотрит экран
- После приёмки **сам шлёт вам скрины** из облака

Подробно: `docs/CLIENT_CLOUD_IOS.md`

### Один раз от вас

1. Аккаунт на https://mobilenext.ai  
2. Перезапуск MCP в Cursor  
3. При первом вызове облака — войти в браузере и разрешить доступ  

Дальше — без вас.

## Запрет для Клиента

Не писать пользователю «запустите эмулятор / Simulator».
