# Как Клиент проверяет приложение (для людей)

## Коротко

Раньше в правилах было написано «смотри эмулятор», но **инструмента «глаз» не было** — Playwright смотрит сайты в браузере, а не наше приложение на телефоне.

Сейчас Клиент умеет (через MCP):

1. Увидеть список эмуляторов/телефонов  
2. Открыть приложение  
3. Сделать скриншот экрана  
4. Нажать, свайпнуть, проскроллить  
5. Проверить вёрстку и сценарий  
6. Выписать тикеты `C-*` команде со скринами  

## Android (этот компьютер)

У вас уже есть Android SDK и виртуальные телефоны (`Pixel_7_Pro` и др.).

Нужно:

1. Запустить эмулятор (Android Studio → Device Manager, или командой emulator)  
2. Установить свежую сборку APK (Деплоер)  
3. В чате сказать: «Клиент, прими через mobile-mcp»  
4. Перезапустить Cursor после обновления MCP, если серверы не подхватились  

## iPhone

На **Windows** нет официального iOS Simulator.

Варианты:

- облако **Mobile Next Cloud** (тот же `mobile-mcp`)  
- Mac с Xcode Simulator  
- TestFlight + ваши скрины (Клиент оформляет тикеты)
